# 🎓 Student Management System

A desktop application built with Python to simplify the management of student information. This project allows users to add, update, search, and delete student records while keeping all data organized in a local SQLite database.

The project was developed to strengthen my understanding of Python programming, database management, and software development principles.

---

## 🚀 Features

- Add new student records
- Update existing student information
- Delete student records
- Search students by ID or name
- View all students
- Record attendance
- Manage student grades
- Store data using SQLite
- Simple and easy-to-use interface
- Input validation to reduce errors
